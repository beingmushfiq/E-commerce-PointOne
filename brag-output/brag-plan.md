# Brag Plan: CENTERPOINT

## What is this app?
CENTERPOINT is an enterprise-grade, dual-edition commerce platform — Standalone or SaaS — that unifies a Visual CMS storefront, multi-warehouse inventory, pure double-entry accounting, Bangladesh-local payment gateways, and a local-first AI assistant, all engineered to run on shared cPanel hosting with zero fabricated operational data.

## The angle
Most commerce platforms make merchants stitch tools together. CENTERPOINT is the one that holds the whole operation. The video opens on the chaos of running commerce in pieces, then drops into the actual Studio Dashboard where real metrics counter-tween upward in champagne gold — proving the platform isn't just marketing. The punchline is the double-entry ledger: a system so rigorous that every posted journal entry is a mathematical guarantee. That's not a feature card. That's a commercial operation.

## Hook (first 2–3 seconds)
Text types in on obsidian: **"Your commerce operation runs in how many tools?"** — no answer given. Hard cut to the CENTERPOINT Studio Dashboard as the gold metric counters spin up. The contrast between the question and the calm, rich interface is the hook.

## Key moments (the middle)

- **The Studio Dashboard** — 4 metric cards animate in one by one (Net Sales ৳ 24.8L / 184 Orders / AOV ৳ 13,505 / 412 Customers) in JetBrains Mono, gold accent, on the dark surface.
- **The Visual CMS 3-Panel Editor** — left panel (section blocks), center canvas (live storefront preview), right property inspector — all three visible simultaneously. Text label: "Build it. Ship it. Live."
- **The Double-Entry Ledger** — journal entry card: `Dr. bKash Settlement / Cr. Commerce Revenue ৳ 95,000 ✓ Balanced`. Followed by `SUM(Debits) == SUM(Credits)`. This is the most audacious line in the codebase — use it verbatim.

## Outro / punchline
Logo mark fades in on obsidian. Headline: **"One Platform. Complete Commerce."** Sub-label in Cormorant Garamond italic: *Developed by DevCenterPoint.* Then the URL: `centerpoint.devcenterpoint.com` in JetBrains Mono amber.

## User flow worth showing
1. **Entry** — Merchant opens Studio Dashboard, metric counter-tweens begin (Net Sales, Orders, AOV, Customers).
2. **Key action** — clicks into the Double-Entry Accounting Ledger, sees the balanced journal builder.
3. **Result** — Journal entry posts: `JRN-2026-042 ✓ Balanced`. Ledger guard confirmed. Operation complete.

## Storyboard

### Scene 1 — Hook — 3s
**On screen:** Pure obsidian background (`#09090B`). Text types in character by character in Plus Jakarta Sans, white, centered:
> "Your commerce operation. How many tools?"

The question hangs for 1.5s, then a hard cut.
Sequential/interaction: Yes — text types out character by character (subtle keyboard SFX, sparse, low volume)
Audio intent: Quiet, anticipatory — music bed just barely audible, building tension
Audio-coupled idea: Per-character type with 2–3 randomized `keyboard/keypress-*.wav` at 0.3 volume — not every character, just the rhythm of typing
Music: cinematic bed, fade in from near-silence
Transition mood: hard cut → Scene 2

### Scene 2 — The Studio Dashboard — 7s (3s–10s)
